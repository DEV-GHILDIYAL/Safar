## Decisions
- Expo SDK 58 (latest at scaffold), RN 0.88, Reanimated 4.7 + worklets (babel plugin auto via babel-preset-expo).
- `.npmrc` `legacy-peer-deps=true`: expo-router's web deps pull react-dom with a stricter react peer.
- Routes in `src/app/`; `@/*` path alias to `src/*`.
- Accent colour saffron `#FF7A3D` on near-black `#0A0C10`; icons from MaterialCommunityIcons.
- No RNGH gesture APIs used (v3 API churn); swipe/drag via RN PanResponder or FlatList paging.
- Full schema (trips/chapters/memories) created in migration 1; all repos written in phase 1.
- Home hero shows the current trip, or the nearest upcoming one when nothing is current.
- Chapter `sort_order` defaults to `start_at`; reorder swaps within a day only.
- Picked cover stays a source URI until Save, so cancelled forms leave no orphan files.
- `.gitattributes` forces LF (CI runs on Linux).
- Shared-element transition is hand-rolled: card rect → detail header animates left/top/width/height
  (no Reanimated sharedTransitionTag; it is experimental). Detail route uses a short native fade.
- Reorder = up/down buttons in the expanded card (within a day); long-press a card to edit.
- Chapter title is optional; defaults to "<Type> to <To>" or the type label.
- "Now" marker shown only while the trip is current.
- CI: ubuntu, Node 22, JDK 17, `prebuild --clean`, ABIs arm64-v8a/armeabi-v7a/x86_64 (x86 dropped for
  size/time). Signing = prebuild template `debug.keystore` via `signingConfigs.debug` (stable signature).
  APK named `safar-<tag>.apk`; release notes auto-generated.
- Memory `taken_at` = EXIF DateTimeOriginal for gallery picks, else now. Viewer uses a paging FlatList
  (no pinch-zoom yet); caption saves on blur/submit.
- Icon/splash are generated by `scripts/gen-icons.mjs`: saffron disc with an "S" road + destination dot.
